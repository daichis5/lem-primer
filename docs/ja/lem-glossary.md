# 用語集

3資料で共通して使う用語と記号をまとめる．定義は本シリーズの中での用法であり，文献によって表記や符号規約が異なる場合がある．

```{glossary}
すべり面
  斜面の中に仮定する，崩壊が起こると想定した曲面．円弧，楕円体，複合面，自由曲面など，手法や実装によって表現が異なる．LEMは，この面を「与えられたもの」として安全率を計算する．

すべり土塊
  すべり面より上側の土の塊．すべり面に沿って動くと想定する対象．

スライス
  2次元解析で，すべり土塊を鉛直に分割した細片．

カラム
  3次元解析で，すべり土塊を平面上の2方向に分割した柱状要素．スライスの3次元版にあたる．

応力テンソル
  点ごとに定義される2階テンソル $\boldsymbol{\sigma}$．ある面に働く力そのものではなく，任意の面に働く力を取り出すための量．

表面力
  traction．単位面積あたりの力ベクトル $\boldsymbol{t}=\boldsymbol{\sigma}\boldsymbol{n}$．応力テンソルと外向き単位法線 $\boldsymbol{n}$ から Cauchy の公式で決まる．

法線応力
  表面力の法線成分の大きさ $\sigma_n$．本シリーズでは地盤工学の慣例に従い，圧縮を正とする．

間隙水圧
  土の間隙を満たす水の圧力 $u$．等方的に作用するため，表面力のせん断成分は直接には変えない．

有効法線応力
  $\sigma_n'=\sigma_n-u$．土粒子骨格が実際に受け持つ法線応力で，せん断強度を支配する．

Mohr–Coulomb則
  $\tau_f=c'+\sigma_n'\tan\phi'$．現在の有効法線応力の下で「発揮できる」せん断強度の上限を与える破壊規準．$c'$ は有効粘着力，$\phi'$ は有効内部摩擦角．

せん断強度
  $\tau_f$．破壊時に発揮できるせん断抵抗の上限．いま作用しているせん断応力ではない．

動員せん断応力
  $\tau_m$．つり合いを保つために実際に働いているせん断応力．強度のうち何割が使われているかを表す．

抵抗力
  すべりに抵抗する側の量をまとめた入門的な呼び方．第1資料の導入では，駆動力と対にして安全率を説明するために使う．厳密な用語ではない．

駆動力
  すべり土塊をすべらせようとする側の量をまとめた入門的な呼び方．自重の斜面に沿う成分などが該当する．抵抗力と同じく，正確な定義を与える前の言い方である．

安全率
  $F_s=\tau_f/\tau_m$．すべり面全体で共通の1つの値と仮定するのが標準的なLEMの立場．入門的には抵抗力と駆動力の比として説明されるが，実際に比を取る対象は手法によって異なり，Fellenius法やBishop簡便法では円弧中心まわりのモーメントの比になる．

底面法線力
  $N_i$．第 $i$ 要素の底面に作用する全法線応力の面積分．すべり土塊にはたらく向きは $-N_i\boldsymbol{n}_i$．

底面間隙水圧合力
  $U_i$．第 $i$ 要素の底面にわたる間隙水圧の面積分．$N_i-U_i$ が有効法線力になる．

底面せん断力
  $T_i$．第 $i$ 要素の底面で動員されるせん断力の大きさ．$T_i=\{c_i'A_i+(N_i-U_i)\tan\phi_i'\}/F_s$．

スライス間力
  隣接するスライスが互いに及ぼす内力．2次元では法線成分 $E$ とせん断成分 $X$ に分ける．3次元では2方向の境界に対して定義する．

空間離散化
  連続的な形状・荷重・応力分布を，有限個のスライスまたはカラムと合力で表現する操作．

静力学的不静定性
  static indeterminacy．未知量の数が独立なつり合い式の数を上回り，つり合いだけでは内力分布が一意に決まらない状態．

不静定性の解消
  closure．内力の一部を無視する，内力の方向や成分比を仮定する，使うつり合い条件を限定する，といった追加仮定によって，問題を解ける形にする操作．各LEMの違いは主にここにある．

簡便法
  内力の一部，または満たすつり合い条件の一部を省略する手法．Fellenius法，Bishop簡便法，Janbu簡便法など．

静力学的に完全な方法
  内力の方向を仮定したうえで，力とモーメントのつり合いをすべて満たす手法．Spencer法，Morgenstern–Price法など．ここでの「完全」は仮定した内力モデルの内部での話であり，連続体としての厳密解を意味しない．

全体すべり方向
  3次元で，すべり土塊全体が動くと仮定した代表的な移動方位 $\boldsymbol{d}$．安全率を左右する定式化上の変数であり，可視化用の矢印ではない．

局所すべり方向
  各カラム底面の接平面内で仮定したすべりの向き $\boldsymbol{m}_i$．全体すべり方向を底面の接平面へ投影して定める方法などがある．

臨界すべり面
  探索したすべり面の族の中で，安全率が最小になる面．安全率の計算と臨界面の探索は別の問題である．
```
