# 用語集

3つの資料で共通して使う用語と記号を，ここにまとめる．定義は，このシリーズでの使い方である．文献によっては，書き方や符号規約が違うことがある．

```{glossary}
すべり面
  斜面の中に仮定する，崩れるときにすべると想定した曲面．円弧，楕円体，複合面，自由曲面など，表し方は手法や実装によって違う．LEMは，この面を与えられたものとして，安全率を計算する

すべり土塊
  すべり面より上の土の塊．すべり面に沿って動くと想定する

スライス
  2次元の解析で，すべり土塊を鉛直に分けた細片

カラム
  3次元の解析で，すべり土塊を水平面内の2方向に分けた柱状の要素．スライスを3次元にしたもの

応力テンソル
  点ごとに定まる2階のテンソル $\boldsymbol{\sigma}$．ある面に働く力そのものではなく，どの面に働く力も，ここから取り出せる

表面力
  traction．ある面に働く，単位面積あたりの力のベクトル $\boldsymbol{t}=\boldsymbol{\sigma}\boldsymbol{n}$．応力テンソルと外向きの単位法線ベクトル $\boldsymbol{n}$ から，Cauchyの公式で決まる

垂直応力
  表面力の法線成分の大きさ $\sigma_n$．このシリーズでは，地盤工学の慣例に従い，圧縮を正とする

間隙水圧
  土の間隙を満たす水の圧力 $u$．等方的に働くので，表面力のせん断成分を直接は変えない

有効垂直応力
  $\sigma_n'=\sigma_n-u$．土粒子の骨格が実際に受け持つ垂直応力で，せん断強度を左右する

Mohr–Coulomb則
  $\tau_f=c'+\sigma_n'\tan\phi'$．今の有効垂直応力のもとで発揮できる，せん断強度の上限を与える破壊規準．$c'$ は有効粘着力，$\phi'$ は有効内部摩擦角

せん断強度
  $\tau_f$．破壊するときに発揮できるせん断抵抗の上限．今働いているせん断応力ではない

動員せん断応力
  $\tau_m$．つり合いを保つために，実際に働いているせん断応力．強度のうち，どれだけが使われているかを表す

抵抗力
  すべりに抵抗する側の力．滑動力と対にして，安全率を「抵抗力÷滑動力」と説明するときに使う

滑動力
  すべり土塊をすべらせようとする側の力．自重のすべり面に沿う成分などにあたる．つり合っている土塊では，すべり面が動員しているせん断力と大きさが等しい

安全率
  $F_s=\tau_f/\tau_m$．標準的なLEMでは，すべり面全体で共通の1つの値と仮定する．入門的には，抵抗力と滑動力の比として説明する．ただし，実際に比をとる対象は手法によって違い，Fellenius法や簡易Bishop法では，円弧の中心まわりのモーメントの比になる

底面垂直力
  $N_i$．第 $i$ 要素の底面にわたって，全垂直応力を面積分した値．すべり土塊に働く向きは $-N_i\boldsymbol{n}_i$

底面の間隙水圧の合力
  $U_i$．第 $i$ 要素の底面にわたって，間隙水圧を面積分した値．$N_i-U_i$ が有効垂直力になる

底面せん断力
  $T_i$．第 $i$ 要素の底面で動員されているせん断力の大きさ．$T_i=\{c_i'A_i+(N_i-U_i)\tan\phi_i'\}/F_s$

スライス間力
  隣り合うスライスが互いに及ぼし合う内力．2次元では，境界の面に垂直な成分 $E$（スライス間の垂直力）と，せん断成分 $X$ に分ける．3次元では，2方向の境界のそれぞれで考え，カラム間力と呼ぶ

空間の離散化
  連続的な形，荷重，応力の分布を，有限個のスライスやカラムと合力で表す操作

静力学的不静定性
  static indeterminacy．未知量の数が独立なつり合い式の数より多く，つり合いだけでは内力の分布が一意に決まらない状態

不静定性の解消
  closure．内力の一部を無視する，内力の向きや成分の比を仮定する，使うつり合いの条件を一部に限る，といった仮定を加えて，問題を解ける形にする操作．LEMの各手法の違いは，主にここにある

簡便法
  内力の一部や，満たすつり合いの条件の一部を省く手法．Fellenius法，簡易Bishop法，簡易Janbu法など

静力学的に完全な方法
  内力の向きを仮定したうえで，力とモーメントのつり合いをすべて満たす手法．Spencer法，Morgenstern–Price法など．ここでの「完全」は，仮定した内力のモデルの中での話で，連続体としての厳密解という意味ではない

全体すべり方向
  3次元で，すべり土塊全体が動くと仮定した代表の向き $\boldsymbol{d}$．安全率を左右する，定式化の中の変数で，結果を見せるための矢印ではない

局所すべり方向
  各カラムの底面の接平面内で仮定した，すべりの向き $\boldsymbol{m}_i$．全体すべり方向を，底面の接平面に射影して定める方法などがある

臨界すべり面
  探索したすべり面の族の中で，安全率が最小になる面．安全率の計算と，臨界すべり面の探索は，別の問題である
```
